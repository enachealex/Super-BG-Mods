# Super Battle Golf mods

BepInEx mods for Super Battle Golf (Steam).

| Mod | What it does |
| --- | --- |
| [SBGSplitscreen](SBGSplitscreen/) | Local splitscreen for up to 4 players in one game window, plus host-side dueling pistol tuning. |

Each mod folder has its own README with install, build and design notes.

No game files are included in this repository. Building needs a local install of the game and BepInEx.
